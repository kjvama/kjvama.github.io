# KJVAMA

KJVAMA is a website dedicated to the King James Bible.

KJVAMA provides resources for reading, studying, and understanding
the King James Bible.

## Website

https://kjvama.com/

## Repository

This repository contains the files used to publish the KJVAMA website
through GitHub Pages.

## Contents

- `weekly/` — Weekly Bible study materials
- `code/` — System and utility pages
- `css/` — Stylesheets
- `js/` — JavaScript files
- `images/` — Image resources
- `test/` — Test pages
